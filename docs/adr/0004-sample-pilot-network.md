# ADR 0004: Invented sample network for the MVP

- Status: Accepted
- Date: 2026-11-10

## Context
No licensed, surveyed street data was available for the hackathon.

## Decision
Use "Pilot zona A", an invented network of 17 nodes and 22 segments, and label it as sample data on every screen.

## Consequences
Honest demo, no real-world claims. A real pilot needs licensed map data and a field survey.
