# Urbiva Impact

Infrastructure intervention simulation. Route: `/impact?barrier=<id>`. Status: **implemented** on **sample data**.

## Features

- Barrier selector (confirmed barriers that block wheelchairs).
- Views: comparison, before, after.
- Reachability maps with numbered destinations; new destinations highlighted.
- Deltas: destinations within 15 minutes, passable segments, route length to Poliklinika.
- Generated explanation, assumptions and a "sample scenario" notice.
- Empty and invalid scenario states.

Method and numbers: [impact-simulation.md](../impact-simulation.md).
