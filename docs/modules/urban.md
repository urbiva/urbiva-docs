# Urbiva Urban

Infrastructure intelligence dashboard for planners. Route: `/urban`. Status: **implemented** on **sample data**.

## Features

- Profile tabs (Piyada, Əlil arabası, Uşaq arabası).
- Four metrics from the graph: surveyed segments, barrier records, passable segments for the profile, destinations within 15 minutes.
- Segment-state map: passable, confirmed barrier, unverified or unknown.
- Barrier list with filters (all, confirmed, pending), newest report selected first.
- Detail with source and note; confirm or reject unverified and AI-estimate records.
- "Simulate intervention" enabled only for confirmed barriers that block wheelchairs; opens Impact.

## Not implemented

Infrastructure prioritisation view (designed in Figma only).
